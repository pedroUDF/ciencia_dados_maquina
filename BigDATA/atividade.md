## Questão 1
**Pergunta:** Em 3 frases, explique o que é Big Data e por que ele é importante para Ciência de Dados e Machine Learning.

**Resposta:** 
**O que é Big Data:**
O termo Big Data refere-se quando há um conjunto massivo de diversos tipos de dados que sistemas tradicionais de análise de dados não conseguem suportar, analisar e gerenciar. 
**Por que é importante para Ciência de Dados:**
Quanto maior a quantidade de dados disponíveis, mais a ciência de dados pode se beneficiar, podendo encontrar padrões, variedade e produzir insights mais precisos. 
**Por que é importante para Machine Learning:**
Para o Machine Learning, ter acesso a um amplo acervo de dados, como nas Big Datas, o torna capaz de maximizar sua capacidade de raciocínio, dependendo cada vez menos de intervenção humana.

## Questão 2
**Pergunta:** O desafio dos 5 Bilhões

**Resposta:** 
Tendo em vista o desequilíbrio da grande quantidade de dados, comparada com a capacidade de processamento disponível (16GB RAM), a estratégia adotada seria um processamento por lotes. A leitura dos arquivos seriam em blocos, teria um breve tratamento de dados, manteria os arquivos necessários e excluiria os desnecessários.
